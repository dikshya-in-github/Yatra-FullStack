Tickets

Generated e-tickets (Master Plan §2.1 #9), read from /api/admin/tickets — the PNR + ticket number the customer printed at eticket.html. Search, both filters and paging are queries, and the Status column is the ticket's own state (ISSUED → Issued, CANCELLED → Voided), with the booking's state beside it — the two are independent: a cancelled booking's document stays Issued, because nothing in the API voids a ticket. This view is read-only — a document is issued by the checkout when a payment settles, and cancelling a booking starts at Bookings.
